## 1. 三条硬约束（先读）

1. **运动方向永远取速度矢量，永远不取 yaw。** 感知的 yaw 在消歧失败时是
   180° 二义的轴向（`Obstacle.msg` 的 `heading_resolved`，P6-S3 加），猜错 =
   预测逆行，症状出现在 P7（"对方要过来" 的误判）。yaw 只用于沿轨迹摆盒子
   （碰撞盒对 180° 对称）。守卫：`HeadingComesFromVelocityNotYaw`，注入验红。
2. **不用 classification 选模型。** 实测 25%/48% 判对且无判据在守。选择只用
   速度、尺寸、车道归属。`TargetSnapshot` 结构上没有 classification 字段。
3. **声称的速度必须有净位移背书。** S1 体检实测：结构物（墙沿/杆件）航迹
   |v|>0.5 占 **24.5%**、p95=5.5 m/s —— 簇形交替让 KF 报出高速度而位置原地摆。
   没有背书 ⟹ 按静止处理（"不知道就别编"）。守卫：选择器三条用例，注入红 3。

## 2. 恒速与静态模型

- 恒速：`p(t) = p₀ + v·t`，朝向 = `atan2(v)`，速率 = |v|。解析，无数值积分。
- 静态：全程原地，朝向沿用输入 yaw（只摆盒子），速率 0。
  ⚠️ 静态模型**忽略**输入的速度字段 —— "判它静止"是选择器的职责，
  模型只回答"静止目标该输出什么"。两者分开，选择器才能被独立注入验证。

## 3. 不确定椭圆

半轴（1σ），沿运动方向 / 垂直运动方向：

```
σ_along(t) = σ₀ + σ_v · t          位置误差 + 速度误差的线性传播
σ_cross(t) = σ₀ + ½ · a_lat · t²   未建模横向机动的恒加速度包络
静态：两轴同律 σ(t) = σ₀ + ½ · a_start · t²   （起步方向未知）
```

| 参数 | 值 | 依据 |
|---|---|---|
| σ₀ | 0.2 m | 感知横向位置误差 p95 0.29 / 1.65（p95→1σ）≈ 0.17，留噪 |
| σ_v | 0.15 m/s | 感知速度误差 p95 稳态 ≈ 0.15（CP-P5-B 复测轮） |
| a_lat（行人） | 0.5 m/s² | 1.2 m/s 步速下 0.5 m/s² 持续 2.4 s = 90° 变向。t=3 时 2σ_cross = 4.9 m > 最坏横移 3.6 m（覆盖），且没把整条路盖住（CP-P6-B ⑤ 半轴上限卡它） |
| a_lat（车·恒速） | 0.8 m/s² | 园区弯道侧向加速度 1.56 的一半：无车道信息时"可能在打方向但不会满舵" |
| a_lat（车·车道跟随） | 0.3 m/s² | 车道约束吸收大部分横向自由度；S1 实测 curve_car 对中心线 max 0.21 m |
| a_start | 1.5 m/s² | 园区车最大纵向加速度：静止目标随时可能起步、方向未知 |

⚠️ 椭圆是**行人判据的载体**：过小 = 假自信（覆盖率判据卡），过大 = 没有信息量
（半轴上限判据卡）—— 两头都有判据，这些参数不是自由旋钮。

## 4. 车道跟随

骨架：`nearest_lane`（位置 + **运动方向**）定归属 → 沿 `successors` 枚举车道链
（路口分叉出多假设，概率均分）→ `sample_lane_centerline` 采样成折线（正编号
车道的 180° 翻转在那里做，全仓库一份）→ `ReferenceLine` 弧长参数化 →
`s(t) = s₀ + |v|·t` 沿线取位姿，初始横向偏移 `d₀`（带符号，来自 `project()`）
线性衰减：`d(t) = d₀·max(0, 1 − t/T_decay)`。

| 参数 | 值 | 依据 |
|---|---|---|
| match_max_lateral_m | 2.0 | < 半车道 1.75 + 感知横向 p95 0.29。调大 → 隔壁车道的目标被归进来 |
| match_max_heading_rad | 30° | 车道内摆动 ≪ 30°，斜穿 ≥ 60°、横穿 90°、逆行 180° —— 干净分开。⚠️ 逆行由 nearest_lane 自带的 90° 过滤兜住，**这道门限的独立职责是斜穿**（`RefusesACrossingTarget` 守着 —— 第一版没这条用例，注入"去掉门限"六条全绿） |
| sample_step_m | 0.5 | 最急车道弧 r = 12−1.75 = 10.25 上折线弦高 = step²/8r = 0.003 m ≪ CP-P6-A ② 的 0.01（取 1.0 时弦高 0.012，判据被采样误差吃掉） |
| lateral_decay_s | 2.0 | 车道保持闭环的时间常数量级 |
| max_hypotheses | 4 | 园区路口最多三岔；上限防病态图 |

**三条边界**（CP-P6-A ③④⑦，各有注入记录）：
- 跨 successor 连续（含正编号车道）；正编号不翻 180° 的注入红 4 条；
- 走到头且无后继 ⟹ **如实截断**（点数变少）——不外推、不夹取（夹取 = 末尾
  堆重合点，`path_remaining_m` 那条老陷阱的预测版，注入验红）；
- 归属不成立（横向远 / 方向斜穿或逆行）⟹ 返回空、调用方退恒速 ——
  对折返中的 NPC 不假装能按车道预测。

**弧线判据的解析锚**（独立于实现的推导，campus_map.yaml 手推）：
SE 弯参考线 R=12 圆心 (78,−38)，内圈车道 = r=10.25 的圆。实测 lib 对解析圆
最大偏差 **0.0023 m**（判据 0.01）。3 s、4 m/s 下恒速与车道跟随的末点分歧
解析值 `|(vT − r·sinφ, r(1−cosφ))|`（φ=vT/r）= **6.756 m**，实测 6.762 ——
⚠️ plan.md CP-P6-A ⑤ 原写 5.83：那是**参考线** R=12 的数，车沿的是车道弧
r=10.25。判据修正见 plan（数字变大，分得更开，不是放宽）。

## 5. 模型选择（决策五）

规则顺序即优先级：

```
1. |v| < 0.5           → 静态   （速度方向由噪声主导；tracker 新航迹初速恒 0）
2. |v| > 8.33          → 静态   （ODD 30 km/h：物理上不可能的状态不许外推 ——
                                  S0 墙沿假航迹 11.9/15.5 m/s 的教训）
3. 净位移 < |v|·1s·0.5 → 静态   （S1 的 24.5% 假速度；没有历史 = 不知道 = 不编）
4. length ≥ 2.5        → 车道跟随（尺寸是直接测量：行人/杆 ≤0.5，车 ≥4，隔一整倍）
5. 其余                → 恒速 + 椭圆
```

**已知代价**（如实写，不是缺陷）：
- 规则 3 让真实新目标的预测延迟约 1 s —— 而它的速度本来就没收敛
  （tracker 初速 0），这 1 s 里给出的静态 + 增长椭圆是诚实的输出。
- 规则 2/3 把坏航迹按"静止 + 椭圆"输出而不是不输出 —— SPEC §11 不许
  安全相关数据被过滤；静态输出如实标注"这里有东西、动向不明"。

## 6. 边界（已实现 / 未实现）

| 项 | 现状 |
|---|---|
| 换道假设 | ❌ 车道图没有横向换道边（map_and_routing.md §10），图上枚举不出来 |
| 意图分类 / 概率非均分 | ❌ SPEC 升级路径（意图分类器），v1 概率 = 1/N |
| 行人沿人行道 | ❌ 地图没有人行道语义；行人一律恒速 + 椭圆 |
| 多目标交互（让行/跟驰） | ❌ 每个目标独立预测；那是 P7 行为层的输入不是这里的输出 |
| 遮挡滑行目标 | 照常预测（滑行航迹照常发布是感知的设计）；existence 不进预测 |
